# FJ Watches Analytics Studio · Fine Jewelry Management

A compact static SaaS website for a Fine Jewelry & Watches management and analytics product.

## Core content
- Data visualizations
- Automated performance metrics
- Export reports
- User access controls
- Operational dashboards
- Fine jewelry and luxury watch product analytics

## Pages
- `index.html` — Home
- `directory.html` — Analytics
- `story.html` — Studio
- `workflow.html` — Services
- `contact.html` — Contact (email, phone, address, form and map only)

## Run
No build step is required. Open `index.html` locally or upload the project contents directly to GitHub Pages.
